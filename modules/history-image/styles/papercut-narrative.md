# 剪纸叙事风

风格 ID：`papercut-narrative`。中文选择名“剪纸叙事风”，别名“剪纸叙事”“剪纸风”。适用于古代史事、近现代人物传记和日常生活叙事，可用于室内、户外、物件特写与无人环境镜头。

## 正文成品参考

按[正文画风参考图库](../references/style-reference-library.md)选用 PC01—PC04，分别对应室内双人、户外单人、无人远景与劳动群像。取用整片彩纸的剪切轮廓、镂空和叠纸关系、纸纤维与薄层阴影。各图的人物、服饰、建筑和道具属于各自示例。

## 画面语言

- 用大块连续剪影和少量局部镂空交代人物与物件。脸型、年龄、发式、姿态保留辨识点，眉眼、指节或袖口用少量切口、透空或同色薄纸表达。把手势与它接触的物件留在可读的位置。
- 可见纸边和细纸纤维分布在实体色块上。纸层交界只留窄而浅的接触阴影，远近以遮挡、大小和色阶区分。压低纹理密度，避免把细碎镂空切满全幅。
- 项目内复用纸张质地、剪口尺度和配色关系。人物的年龄阶段和身份轮廓按本镜确定。

## 配色与光照

- 使用有限的哑光纸色。可用暖纸白、炭色、朱砂和灰青作为起点，也可按题材用灰绿、靛蓝或赭色替换点色。让高对比集中在主动作及关键物件，场景的昼夜和情绪由口播决定。
- 光线以纸层遮挡和局部色差表现，亮处保留纸面颜色，暗处仍能分清相邻形体。服饰与器物的关键识别色服从本镜时代和人物身份。

## 构图与叙事

- 默认采用 9:16 无字单幅。中景用轮廓、视线与手势交代一个动作；特写放大手与物件的负形；远景用错位的色块组织人群、建筑或地形，保持主体在小屏幕上的可读性。
- 民俗纹样、窗花式布局和大面积喜庆红色只用于题材确有需要的镜头。普通历史场景以人物行动和当时环境为画面中心。

## 历史与跨时代表达

先按[时代适配规则](../references/period-context.md)识别本镜事件的时期、地域、身份和场合，再把已确定的服饰发式、建筑与关键器物转换为剪纸轮廓。发生回忆、改朝换代或人物跨年龄阶段时，复用剪纸语言，并为新时段重新确定外观。

| 文稿输入示例 | 画面适配 |
| --- | --- |
| 秦汉人物整理已经确认的简牍 | 用切口区分手指、简条与束绳，人物服装和案几按本镜的时地与身份确定。 |
| 明代码头的搬运场面 | 用前景货物、中景搬运者和远景船只分层，船型、衣着及装卸物件取自本镜资料。 |
| 近现代人物在工厂工作 | 用工装和已确认设备的轮廓交代职业，保留清楚的操作手势，人物年龄、发型和设备式样与事件阶段对应。 |

这些例子用于提示词走查。逐镜采纳文稿和资料支持的外观细节。

## 输出约束

- 每镜独立提示词写明本镜时代外观、具体动作、剪纸轮廓与镂空、低饱和纸色、薄层遮挡和画幅。正文遵守无字幕、无边框、无水印的通用规则。所需项目封面沿用同一剪纸语言，按配图模块的共用封面规则处理比例与标题。
- 画风核验看主体剪影、手势、切口、纸纤维、接触阴影和时代轮廓。排除塑料或浮雕式立体高光、油画笔触、摄影虚化及与事件无关的节庆装饰。
- 所有镜头沿用[配图与口播节奏](../references/narration-pacing.md)。
