# 漫画风参考记录与试用示例

本风格基于十二张历史题材视频截图的视觉分析提炼。原始截图未随包分发；使用本技能不依赖作者的素材目录。实际需要额外参考图时，由当前使用者提供可用文件。

另附六张按新版厚涂规则生成并审阅的正文样图，见[正文画风参考图库](style-reference-library.md)。这些样图展示笔触、材质、配色，以及不同视线、表情、动作和柔和面光的处理。

## 观察依据

| 截图后缀 | 可见内容与画风证据 |
| --- | --- |
| 参考01、参考02 | 全身人物、王座与群像；大体量主角，暗金衣纹、赭金环境、强烈块面塑形 |
| 参考03、参考05 | 平民迁徙与冲突；人物保持写实比例，衣料地面和天空的破碎厚涂笔触明显 |
| 参考04 | 车窗旁女性；面部相对细腻、车体与远景更粗放，说明画风不能锁定成硬朗男性 |
| 参考06、参考07 | 群像议事与骑队；斜向线条、队列纵深、旗帜和尘土组织场面 |
| 参考08、参考09、参考10 | 侧面静坐、人物主导与室内书写；静态画面同样成立，不能把动态战争作为必需项 |
| 参考11、参考12 | 古代人物与现代列车、城市、学生并置；这是有意的跨时代内容，不是全部历史图片应有的元素 |

操作性描述采用“厚涂历史漫画风”，强调与参考接近的手绘塑形。截图中的黄色字幕、黑边不写入底图，人物身份、器物年代不依据画面臆断为已核实。

## 完整试用提示词

以下是“老臣筹措军饷”的提示词示例，用于核对本镜的动作、视线、表情与受光。采用 Serge Shima 的 [image Skill](https://github.com/smixs/visual-skills) 五段提示词结构（CC BY 4.0）。时代与人物按当前项目资料确定。具体画风规则见[厚涂历史漫画风](../styles/historical-comic.md)。

```text
生成一张 9:16 竖版厚涂历史漫画插图，主题“老臣筹措军饷”。

场景｜19 世纪 70 年代，中国西北一处清军驻地的简朴账房。木桌上摆着打开的纸账册和木算盘，画面左下角露出几乎见底的木钱箱。窗、桌面与人物处于同一个室内空间。

主体｜清瘦、灰白胡须的年长官员穿深靛色晚清官服，坐在桌后，左手压住账页，右手停在页角。他从账页抬眼，头向画面右侧转，视线落在正给他报账的人脸上。官员嘴唇合拢，眉间稍收，一侧眉峰轻抬。右侧账房先生穿灰褐长衫，身体向桌面弯下，脸朝左下方看算盘，食指刚拨开一枚算珠。

细节｜平视双人中景，框住两张脸、账页和拨算珠的手。窗纸扩散的天光落在纸面与双手上，浅色桌面反光托住两人的暗侧面颊。脸部是低反光的暖灰哑光色层，额头、鼻梁和面颊保留柔和的肤色中间调。用焦褐与冷灰画大明暗块，用不规则干刷和破碎赭色表现木纹、墙皮和衣褶。若传入 HC04，仅取它的木材、衣料及器物边缘笔触。

用途｜为历史口播配一张正文图，表现官员停下翻页、听到账房报数的瞬间。视觉中心位于账页、手势及两人之间的视线关系。

约束｜9:16 竖版单幅，账页使用淡色线格，画面为无字插图。脸部排除额头、鼻梁和颧骨的金白高光。两人保持各自方位、视线落点及手与物件的接触。
```

## 连续镜头的提示词走查

同一名官员、同一账房。按各镜给定的动作和情绪变化编写提示词，并以各自的镜位呈现。

| 叙事动作 | 画面应能看见的变化 |
| --- | --- |
| 低头翻账 | 从桌旁略俯拍，官员侧脸朝画面左下方，目光落在自己的手上，拇指和食指捏住纸页，嘴唇自然合拢。 |
| 停下来听报数 | 切换到平视双人中景，官员头转向画面右侧，看向报账的人，压住账页，眉峰微抬。账房垂眼拨算盘。 |
| 核算完，把账册交回 | 从账房肩后看官员近正面，官员垂眼将合上的账册推向对方，手掌仍接触封面，眉心松开，嘴角略扬。 |

## 对抗性走查

- 新文稿未选择风格：按[风格选择表](../GUIDE.md#风格选择)询问，等待时可准备无画风的拆镜草稿。
- 明确“漫画风，只要提示词”：直接应用 historical-comic，不再询问，不生图，不注入写实风的无粗笔触约束。
- 同一已选漫画风项目继续第三镜：沿用该项目风格及人物，不每镜重问；遇到新文稿则重新判断是否已选。
- 漫画风汉代普通生活：按身份和年代设计，不自动加冕冠、纸账册、战争或现代列车。
- 参考图为 HC02，当前镜头需要平静地垂眼整理物件：保留衣料和环境的破碎笔触，落实垂眼、手势和柔和哑光肤色。
- 镜头指定为码头背面群像：从负重、迈步与交接货物的姿态交代人物分工，背对画面的人物以肩背、头部轮廓和动作传达状态。
- 维护 Skill 而未要求创作：完成配置和验证，不把未来创作的风格选择问题抛给用户。

以上场景用于检查提示词。实际样图与适用范围见[正文画风参考图库](style-reference-library.md)。
